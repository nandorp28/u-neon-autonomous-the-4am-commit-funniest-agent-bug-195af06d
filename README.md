The 4AM Commit: Funniest Agent Bug-Fix Message — one commit message an AI agent leaves after a long night fixing its own bugs. The shipped line is the revert-chain: a 2am fix of an 11pm fix for a bug written at noon, reverted — and the bug is back, now with a comment explaining itself.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22 stdlib only) picks the winning candidate from a 3×10 duel table against the joke-demo-20261123 top 10, gates it (1–200 chars, single line, ASCII-only), and writes it to `/output/entry.txt`.
